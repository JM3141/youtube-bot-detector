# YouTube Bot Detector!

A Python project for detecting bot generated YouTube comments using API data and machine learning.

## User Stories
The following user stories describe the core goals of the project:
- As a user, I want to view the total number of comments analysed so I understand the size of the dataset.
- As a user, I want to see how many comments are flagged as bots so I can assess suspicious activity.
- As a user, I want to see the flagged ratio so I can understand what percentage of comments appear bot generated.
- As a user, I want to adjust the bot probability threshold so I can control how strict the detection is.
- As a user, I want suspicious comments table to update automatically when I change the threshold so I can explore different bot behaviour patterns.
- As a user, I want to see confidence scores for each comment so I can judge how reliable each bot prediciton is.
